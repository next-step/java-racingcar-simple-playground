# 🚗 자동차 경주 게임 (Car Racing Game)

## 🎯 게임 개요

이 게임은 여러 대의 자동차가 경주를 펼치며, 가장 멀리 이동한 자동차를 우승자로 선정하는 콘솔 기반 게임입니다.

## 📌 게임 진행 방식

- **자동차 대수 입력**: 몇 대의 자동차가 경주할지 입력합니다. (2대 이상)
- **시도 횟수 입력**: 경주가 진행될 라운드 수를 입력합니다. (1회 이상)
- **자동차 이름 입력**: n 대의 자동차의 이름을 입력합니다. (1글자 이상 5글자 이하)
- **경주 진행**: 각 라운드에서 자동차가 이동하며, 이동 결과가 출력됩니다.
- **최종 결과 발표**: 모든 라운드가 끝나면 가장 멀리 간 자동차가 우승자로 발표됩니다.

## 🚀 실행 방법

1. 프로그램을 실행합니다.
2. 자동차 대수와 시도 횟수를 입력하여 경주를 시작합니다.
3. 각 라운드의 이동 결과를 확인하며 경주를 진행합니다.
4. 최종 우승자를 확인하세요! 🎉

## 🛠 주요 기능

- **자동차 이동 로직**: 랜덤한 속도로 이동하며, 특정 속도 이상이면 전진합니다.
- **라운드 진행**: 입력한 횟수만큼 라운드를 반복합니다.
- **우승자 결정**: 가장 멀리 이동한 자동차를 찾고 우승자를 발표합니다.

## 요구사항
- [v] 게임 개여 및 진행 방식 정리
- [v] 필요한 기능 도출(입력, 진행, 결과 처리 등)

## 클래스 설계
- [v] Car: 자동차 상태 관리
- [v] CarRunner: 게임 진행
- [v] RaceInput: 입력 처리
- [v] WinnerFInder: 우승자 판별
- [v] RaceOutput: 출력 처리
- [v] CarFactory: 자동차 객체 생성
- [v] CarName: 자동차 이름 예외처리
## 리펙토링
- [v] 클래스 역할 정리
- [] 불필요한 코드 제거 및 정리

## 테스트
- [v] 정상 입력값 테스트
- [v] 잘못된 입력값 테스트
- [v] 공동 우승자 테스트
- [v] 자동차 이동 로직 테스트
