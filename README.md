# 🚗움직이는 자동차 게임 1단계

## 🎯 게임 개요
이 프로젝트는 사용자가 입력한 자동차가 목표 지점까지 도달하는 **간단한 레이싱 게임**입니다.  
자동차는 **랜덤한 숫자(0~9)**를 받아, 특정 조건을 만족할 경우에만 앞으로 전진합니다.

---

## 📌 게임 규칙
1. **자동차의 이름을 입력받습니다.**
2. **자동차의 목표 지점을 정수로 입력받습니다.**
3. 게임은 **자동차가 목표 지점을 넘을 때까지 반복됩니다.**
    - 매 턴마다 `0~9` 사이의 랜덤한 정수를 생성합니다.
    - 랜덤 값이 `4 이상`일 경우, 해당 값만큼 자동차가 전진합니다.
    - `3 이하`일 경우, 자동차는 그대로 멈춥니다.
    - 매 턴마다 **자동차의 현재 위치가 출력됩니다.**
4. **자동차가 목표 지점을 넘어가면 게임이 종료됩니다.** 🎉
