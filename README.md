# 🏎️ 자동차 경주 게임

## 📝 프로젝트 소개
사용자가 입력한 자동차 이름과 시도 횟수를 바탕으로 자동차 경주를 진행하고, 최종 우승자를 가려내는 콘솔 기반 애플리케이션입니다. 객체지향적인 분리와 단위 테스트 작성을 목표로 구현되었습니다.

## 기능 요구사항

**[게임 규칙]**
* 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
* 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
* 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
* 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
* 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
* 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
* 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.


## 기능 목록

- [x] **자동차 이름 입력 기능**: 쉼표(,)를 기준으로 자동차 이름들을 입력받는다.
- [x] **자동차 이름 검증 기능 (예외 처리)**:
    - [x] 이름이 5자를 초과하는지 검증한다.
    - [x] 이름이 비어있거나 공백(` `)만 있는지 검증하여 예외처리 한다.
- [x] **시도 횟수 입력 기능**: 사용자로부터 경주를 시도할 횟수를 입력받는다.
- [x] **시도 횟수 검증 기능 (예외 처리)**:
    - [x] 입력값이 숫자인지 검증한다.
    - [x] 입력값이 1 이상의 양수인지 검증한다.
- [x] **자동차 전진 기능**: 각 자동차마다 0~9 사이의 무작위 값을 생성하고, 4 이상일 경우 1칸 전진한다.
- [x] **진행 상황 출력 기능**: 매 랩(Lap)마다 각 자동차의 이름과 현재까지 이동한 거리를 하이픈(`-`)으로 시각화하여 출력한다.
- [x] **우승자 판별 기능**: 경주가 모두 끝난 뒤, 가장 멀리 이동한 자동차를 찾아 우승자로 선정한다. (위치가 같은 경우 공동 우승자로 판별한다.)
- [x] **최종 우승자 출력 기능**: 최종 우승자의 이름을 출력한다. 공동 우승자일 경우 쉼표(,)로 구분한다.

## 주요 클래스 및 역할

**[Domain]**
* `Car`: 자동차의 이름과 현재 위치(location) 상태를 가지며, 조건에 따라 전진하는 행위(move)를 담당하는 핵심 객체입니다.
* `RacingGameSetting`: 경주에 참여할 자동차 목록과 총 시도 횟수(Lap) 등 게임의 초기 설정 값을 보관하는 객체입니다.
* `RacingGame`: 설정된 값을 바탕으로 랩(Lap)을 반복하며 실제 자동차 경주를 진행하는 역할을 담당합니다.
* `RacingGameWinner`: 자동차들의 위치를 비교하여 최종 우승자(공동 우승 포함)를 판별해 내는 책임을 가집니다.
* `MakeNumStrategy`: 자동차가 전진하기 위한 조건(숫자 생성)을 추상화하여, 테스트가 용이하도록 만든 인터페이스입니다.

**[View]**
* `InputView`: 사용자로부터 자동차 이름과 시도 횟수를 입력받고, 기본적인 예외 처리를 담당하는 UI 클래스입니다.
* `ResultView`: 매 랩의 진행 상황(하이픈으로 출력)과 최종 우승자 결과를 콘솔 화면에 출력하는 역할을 담당합니다.

**[Main]**
* `Application`: View를 통해 입력을 받고 Domain 객체들을 연결하여 전체 애플리케이션의 흐름을 제어합니다.

## 📖 용어 정리

* **Lap**: 실제 자동차 경주에서 트랙을 한 바퀴 도는 것에서 착안한 용어로, 본 프로그램에서는 '모든 자동차가 1회씩 전진을 시도하는 한 번의 턴'을 의미합니다.
* **Location**: 자동차가 초기 시작점(0)으로부터 성공적으로 전진한 총 칸 수를 의미합니다.
