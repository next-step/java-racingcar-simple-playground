# 🚗 자동차 레이싱 게임

# 프로젝트 개요
이 프로젝트는 간단한 자동차 레이싱 게임이다.
여러 대수의 자동차가 경주를 하며 최종적으로 가장 멀리 이동한
자동차들이 우승하는 게임이다.

## 기능
- 이름을 가진 각 차량을 등록할 수 있다.
- 여러대의 자동차가 경주를 한다.
- 각 차량은 랜덤한 숫자를 기반으로 이동한다.
- 우승자 리스트를 구할 수 있다.

## 게임실행방법
1. 사용자는 (,)를 이용해 이름을 가진 차량 n대를 만든다.(이름은 최대 5자) 
2. 사용자는 게임의 턴 수를 입력한다.
3. 게임을 실행한 후, 우승자들을 찾는다.
