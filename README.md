# 🚗 자동차 경주 게임

Java로 구현한 자동차 경주 게임입니다.

자동차 이름과 경주 횟수를 입력받고, 랜덤한 값에 따라 자동차를 전진시키며 경주를 진행합니다.  
경주가 끝난 후 가장 멀리 이동한 자동차를 최종 우승자로 출력합니다.
