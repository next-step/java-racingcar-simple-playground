# 자동차 경주 게임

## 프로젝트 개요
자동차 경주 게임을 구현했습니다.  
사용자는 경주할 자동차 이름들과 시도할 횟수를 입력할 수 있으며, 주어진 횟수만큼 각 자동차가 전진 또는 멈춥니다.  
게임이 끝난 뒤 가장 멀리 이동한 자동차(들)를 최종 우승자로 판별합니다.

## 기술 스택
- Java
- Gradle
- JUnit5
- AssertJ

## 구현 기능
### Car
- 자동차는 이름을 가진다.
- 자동차는 현재 위치를 가진다.
- 전달받은 숫자가 4 이상이면 전진한다.
- 전달받은 숫자가 3 이하이면 멈춘다.
- 자동차 이름이 공백이거나 5자를 초과하면 예외를 발생시킨다.

### Cars
- 여러 대의 자동차를 관리한다.
- 한 번의 라운드에서 모든 자동차를 전진 또는 멈추게 한다.
- 가장 멀리 이동한 자동차의 위치를 기준으로 우승자를 판별한다.
- 공동 우승자를 처리할 수 있다.

### RacingGame
- 자동차 경주 게임의 진행을 담당한다.
- 한 번의 라운드를 진행한다.
- 우승자 조회와 자동차 목록 조회를 자동차 목록 객체에 위임한다.

### InputView
- 경주할 자동차 이름을 쉼표(,)를 기준으로 구분하여 입력받는다.
- 시도할 횟수를 입력받는다.
- 시도할 횟수는 1 이상만 입력할 수 있다.

### OutputView
- 실행 결과 헤더를 출력한다.
- 매 라운드마다 자동차별 진행 결과를 출력한다.
- 최종 우승자를 출력한다.

### NumberGenerator
- 숫자 생성 역할을 분리하기 위해 `NumberGenerator` 인터페이스를 사용했다.
- `RandomNumberGenerator`는 0부터 9 사이의 랜덤값을 생성한다.
- `TestNumberGenerator`는 테스트에서 원하는 숫자를 순서대로 생성한다.

### Application
- 사용자 입력을 받아 게임을 생성한다.
- 입력한 횟수만큼 라운드를 반복 실행한다.
- 각 라운드 결과와 최종 우승자를 출력한다.

## 테스트
### CarTest
- 4 이상일 때 자동차가 전진하는지 테스트한다.
- 3 이하일 때 자동차가 멈추는지 테스트한다.
- 자동차 이름이 5자를 초과하면 예외가 발생하는지 테스트한다.
- 자동차 이름을 입력하지 않으면 예외가 발생하는지 테스트한다.

### RacingGameTest
- 한 번의 라운드에서 자동차들이 정상적으로 전진 또는 멈추는지 테스트한다.
- 한 명이 우승하는 경우를 테스트한다.
- 다수가 우승하는 경우를 테스트한다.
- 아무도 움직이지 않았을 때 우승자가 없는 경우를 테스트한다.

## 설계 의도
`NumberGenerator` 인터페이스를 도입하여 숫자 생성 역할을 분리했습니다.  
이를 통해 실제 실행에서는 `RandomNumberGenerator`를 사용하고, 테스트에서는 `TestNumberGenerator`를 사용하여 원하는 시나리오를 검증할 수 있도록 했습니다.

또한 `List<Car>`를 `Cars`로 감싸는 방식으로 자동차 목록에 대한 책임을 분리했습니다.  
이를 통해 자동차 목록과 관련된 로직(전체 이동, 최대 위치 계산, 우승자 판별)을 `Cars` 내부에서 관리하고, `RacingGame`은 게임 진행에 집중하도록 구성했습니다.

입력과 출력은 `InputView`, `OutputView`로 분리했습니다.
