# 🚗 자동차 경주 게임 (Car Racing Game)

## 🎯 게임 개요

이 게임은 여러 대의 자동차가 경주를 펼치며, 가장 멀리 이동한 자동차를 우승자로 선정하는 콘솔 기반 게임입니다.

## 📌 게임 진행 방식

- **자동차 이름 입력**: n 대의 자동차의 이름을 입력합니다. (1글자 이상 5글자 이하, 2대 이상)
- **시도 횟수 입력**: 경주가 진행될 라운드 수를 입력합니다. (1회 이상)
- **경주 진행**: 각 라운드에서 자동차가 랜덤 속도(0~9)로 이동하며, 속도가 4 이상이면 전진합니다.
- **최종 결과 발표**: 모든 라운드가 끝나면 가장 멀리 간 자동차가 우승자로 발표됩니다.

## 🚀 실행 방법

1. 프로그램을 실행합니다.
2. 자동차 대수와 시도 횟수를 입력하여 경주를 시작합니다.
3. 각 라운드의 이동 결과를 확인하며 경주를 진행합니다.
4. 최종 우승자를 확인하세요! 🎉

## 🛠 주요 기능

- **자동차 이동 로직**: 랜덤한 속도로 이동하며, 특정 속도 이상이면 전진합니다.
- **라운드 진행**: 입력한 횟수만큼 라운드를 반복합니다.
- **우승자 결정**: 가장 멀리 이동한 자동차를 찾고 우승자를 발표합니다.

## 클래스 설계

### Model
- [v] Car: 자동차 상태 관리
- [v] Cars: 자동차 관리
- [v] CarName: 자동차 이름 예외처리
- [v] CarRacing: 경주 로직 관리 (라운드 진행, 우승자 결정)
- [v] NumberGenerator: 숫자 생성 인터페이스
- [v] RandomNumberGenerator: 무작위 숫자 생성
- [v] TestNumberGenerator: 테스트용 속도 생성.

### View
- [v] InputView: 입력 처리
- [v] ResultVIew: 출력 처리

### Controller
- [v] RacingGame: 게임의 전체 흐름 제어

- [v] Application: 프로그램 실행

### Test
- [v] CarTest: 자동차 이동 로직 검사
- [v] CarNameTest: 자동차 이름 유효성 검사
- [v] CarRacingTest: 경주 진행 및 우승자 결정 테스트
