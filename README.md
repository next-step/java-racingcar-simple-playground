# 자동차 경주

## 자동차

- 자동차는 이름과 현재 위치를 가진다.
- 자동차의 시작 위치는 0이다.
- 이동 판단에 사용하는 정수의 범위는 0~9이다.
- 입력값이 4 이상이면 한 칸 전진한다.
- 입력값이 4 미만이면 현재 위치를 유지한다.

## 경주 진행

- 지정한 횟수만큼 경주를 반복한다.
- 매 회차 자동차별로 이동 여부를 판단한다.

## 우승자 판별

- 경주 종료 후 자동차들의 위치를 비교한다.
- 가장 멀리 이동한 자동차를 우승자로 선정한다.
- 같은 최종 위치의 자동차가 여러 대라면 공동 우승으로 처리한다.

## 결과 출력

- 우승한 자동차의 이름을 쉼표로 구분하여 출력한다.
- 출력 예시: `**,**가 최종 우승했습니다.`
