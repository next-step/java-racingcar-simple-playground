# 🚗 자동차 경주 시뮬레이션 (Car Racing Simulation)

## 🎯 게임 개요
이 프로그램은 하나의 자동차가 목적지까지 이동하는 과정을 시뮬레이션하는 콘솔 기반 게임입니다. 자동차는 랜덤한 속도로 이동하며, 설정한 목적지에 도달하면 시뮬레이션이 종료됩니다.

## 📌 게임 진행 방식
- **자동차 이름 입력**: 자동차의 이름을 입력합니다.
- **목적지 거리 입력**: 자동차가 도착해야 하는 목적지의 거리를 설정합니다.
- **시뮬레이션 진행**: 자동차가 무작위 속도로 이동하며, 현재 위치가 출력됩니다.
- **도착 후 종료**: 자동차가 목적지에 도달하면 게임이 종료됩니다.

## 🚀 실행 방법
1. 프로그램을 실행합니다.
2. **자동차 이름**을 입력합니다.
3. **목적지 거리**를 입력합니다.
4. 자동차의 이동 상황을 실시간으로 확인합니다.
5. 자동차가 목적지에 도달하면 결과 메시지가 출력됩니다. 🎉

## 🛠 주요 기능
- **자동차 이동 로직**: 랜덤한 속도로 이동하며, 속도가 4 이상일 때만 전진합니다.
- **목적지 도착 판별**: 자동차가 설정한 거리만큼 이동하면 도착을 알립니다.
- **자동 진행**: 자동차가 목적지에 도달할 때까지 반복 실행됩니다.
