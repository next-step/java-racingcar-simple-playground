# 자동차 경주 게임

## 프로젝트 개요
자동차 경주 게임의 2단계 기능을 구현했습니다.  
자동차는 주어진 숫자에 따라 전진하거나 멈추며, 여러 자동차가 한 라운드씩 경주한 뒤 가장 멀리 이동한 자동차를 우승자로 판별합니다.  
공동 우승자도 처리할 수 있도록 구현했습니다.

## 기술 스택
- Java
- Gradle
- JUnit5
- AssertJ

## 구현 기능

### Car
- 자동차는 이름을 가진다.
- 자동차는 현재 위치를 가진다.
- 전달받은 숫자가 4 이상이면 전진한다.
- 전달받은 숫자가 3 이하이면 멈춘다.

### RacingGame
- 여러 대의 자동차를 관리한다.
- 한 번의 라운드에서 모든 자동차를 전진 또는 멈추게 한다.
- 가장 멀리 이동한 자동차를 우승자로 반환한다.
- 공동 우승자를 처리할 수 있다.

### NumberGenerator
- 숫자 생성 역할을 분리하기 위해 `NumberGenerator` 인터페이스를 사용했다.
- `RandomNumberGenerator`는 0부터 9 사이의 랜덤값을 생성한다.
- `TestNumberGenerator`는 테스트에서 원하는 숫자를 순서대로 생성한다.

## 테스트

### CarTest
- 4 이상일 때 자동차가 전진하는지 테스트한다.
- 3 이하일 때 자동차가 멈추는지 테스트한다.

### RacingGameTest
- 한 번의 라운드에서 자동차들이 정상적으로 전진 또는 멈추는지 테스트한다.
- 한 명이 우승하는 경우를 테스트한다.
- 다수가 우승하는 경우를 테스트한다.

## 설계 의도
`RacingGame` 내부에서 직접 랜덤값을 생성하면 테스트 결과를 예측하기 어렵다고 판단했습니다.  
그래서 숫자 생성 역할을 `NumberGenerator`로 분리했습니다.  
이를 통해 실제 실행에서는 `RandomNumberGenerator`를 사용하고, 테스트에서는 `TestNumberGenerator`를 사용하여 원하는 시나리오를 검증할 수 있도록 했습니다.
