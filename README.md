## 🏎️ 우승 자동차 구하기

## 📌 프로젝트 개요
**"우승 자동차 구하기"** 프로그램은 여러 대의 자동차가 랜덤한 이동 규칙을 따르며, 가장 많이 이동한 자동차를 우승자로 선정하는 게임입니다.

## 📜 기능 요구사항
 **1️⃣ 참가할 자동차의 수를 정수로 입력받는다.**
- 사용자로부터 **참가할 자동차의 개수**를 입력받습니다.

**2️⃣ 게임을 진행할 라운드 수를 입력받는다.**
- 사용자로부터 **진행할 라운드 수**를 입력받습니다.

**3️⃣ 라운드가 반복될 동안 `n`대의 자동차는 각각 전진 또는 정지한다.**
- 각 라운드마다 **0~9 사이의 랜덤한 값을 생성**합니다.
- 생성된 값이 **4 이상이면 자동차가 전진**, **3 이하이면 정지** 합니다.
- **각 자동차의 이동 결과를 화면에 출력**합니다.

**4️⃣ 주어진 라운드가 모두 끝나면 게임이 종료되고 가장 많이 이동한 자동차가 우승한다.**
- 모든 라운드가 종료되면 **가장 멀리 이동한 자동차를 찾습니다.**
- **최대 이동 거리를 기록한 자동차가 우승**합니다.
- **공동 우승 가능**: 여러 자동차가 같은 최대 거리라면 함께 우승 처리됩니다.
