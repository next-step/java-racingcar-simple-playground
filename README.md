# 🚗 Java 자동차 경주 1~2, 3~4 단계

## 🚀 기능 요구사항

### 1단계 움직이는 자동차
- 자동차는 이름을 가진다.
- 0에서 9 사이의 random 값이 4 이상일 경우 전진하고, 아닐 경우 멈춘다.

### 2단계 우승 자동차 구하기
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 자동차 경주가 끝난 후 누가 우승했는지 구할 수 있다. 
- 우승자는 한 명 이상일 수 있다.

### 3단계 게임 실행
- 자동차 이름을 입력받는다.
- 자동차 이름은 쉼표(,)를 기준으로 구분한다.
- 자동차 이름은 5자 이하여야 한다.
- 경주 횟수를 입력받는다.
- 경주 횟수만큼 자동차 경주가 진행된다.
- 각 라운드마다 자동차는 생성된 값에 따라 전진하거나 멈춘다.
- 0~9 사이의 숫자에서 4 이상이 나오면 자동차는 전진한다.
- 각 라운드의 자동차 위치를 출력한다.
- 자동차 경주가 끝난 후 최종 우승자를 출력한다.
- 최종 우승자는 여러 명일 수 있다.
- 가장 멀리 이동한 자동차가 최종 우승한다.

### 4단계 리팩터링
- 모든 로직에 단위 테스트를 구현한다.
- 단 UI(System.in, System.out) 로직은 제외한다.
- MVC 패턴을 기반으로 리팩터링한다.
- 핵심 비즈니스 로직은 domain 패키지에 구현한다.
- UI 관련 객체는 view 패키지에 구현한다.

## 🚀 프로그래밍 요구사항
- indent depth를 2를 넘지 않도록 구현한다.
- 3항 연산자를 사용하지 않는다.
- else 예약어를 사용하지 않는다.
- 함수의 길이가 15 라인을 넘어가지 않도록 구현한다.

## 🚀 객체 역할
- `Car`: 자동차의 이름과 위치를 관리하고 전진 여부를 결정한다.
- `Cars`: 여러 자동차를 관리하면서 자동차를 움직이게 하고, 최종 우승자를 구한다.
- `RacingGame`: 한 라운드의 진행을 담당한다.
- `NumberGenerator`: 이동 판단을 위한 값을 생성한다.
- `RandomNumberGenerator`: 이동 판단을 위한 값을 0~9 사이의 랜덤값으로 생성한다.
- `InputView`: 사용자로부터 자동차 이름과 경주 횟수를 입력받고, 값을 가공한다.
- `OutputView`: 경주 결과와 최종 우승자를 콘솔에 출력한다.
- `Application`: 객체를 생성하고 전체 실행 흐름을 담당한다.
