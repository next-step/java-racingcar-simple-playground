## 🚗 자동차 경주

### 기능 구현 목록
#### 입력
  - 자동차 이름
    - [x] n대의 자동차가 참여할 수 있다.
  - 시도할 횟수
    - [x] 주어진 횟수 동안 움직인다.

#### 출력
  - [ ] 게임 기록을 반환한다.  
  - [x] 게임 완료 후 우승자를 구한다. (한 명 이상일 수 있다.)

#### 요구사항
- [x] 이름과 위치를 가지고 있다.
- [x] n대의 자동차는 전진 또는 멈출 수 있다.
- [x] 0에서 9 사이에서 random 값을 구한 후 random 값이 4 이상일 경우 전진하고, 3 이하의 값이면 멈춘다.

### 실행결과

```text
경주할 자동차 이름을 입력하세요(이름은 쉼표(,)를 기준으로 구분).
neo,brie,brown
시도할 회수는 몇회인가요?
5

실행 결과
neo : -
brie : -
brown : -

neo : --
brie : -
brown : --

neo : ---
brie : --
brown : ---

neo : ----
brie : ---
brown : ----

neo : -----
brie : ----
brown : -----

neo : -----
brie : ----
brown : -----

neo, brown가 최종 우승했습니다.

```
