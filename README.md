# java-racingcar

## User Requirement

- 사용자는 자동차 이름들과 시도 횟수를 입력한다.
- 각 라운드마다 자동차는 조건에 따라 전진하거나 멈추며, 라운드 결과가 매번 출력된다.
- 정해진 횟수가 끝나면 가장 많이 움직인 자동차가 우승한다. (공동 우승 가능)

## System Requirement

#### 입력

- [x] 경주할 자동차 이름을 쉼표(,)를 기준으로 분리하여 입력받는다.
- [x] 시도할 횟수를 입력받는다.

#### 자동차 생성

- [x] 자동차는 이름을 가진다.
- [x] 자동차 이름은 5자 이하만 가능하다.
- [x] 자동차는 현재 위치를 가지며, 초기 위치는 0이다.

#### 이동 규칙

- [x] 0에서 9 사이의 무작위 수를 구한다.
- [x] 무작위 수가 4 이상이면 자동차는 전진한다.
- [x] 무작위 수가 3 이하이면 자동차는 멈춘다.

#### 라운드 진행

- [x] 입력받은 횟수만큼 라운드를 반복한다.
- [x] 매 라운드마다 각 자동차의 전진 여부를 판단한다.
- [x] 매 라운드 종료 후 각 자동차의 현재 위치를 출력한다.

#### 우승자 판별

- [x] 가장 많이 이동한 자동차를 우승자로 판별한다.
- [x] 최고 위치가 같은 자동차가 여럿인 경우 공동 우승으로 처리한다.

#### 출력

- [x] 실행 결과 헤더를 출력한다.
- [x] 각 자동차의 위치를 이름과 함께 `-`로 출력한다.
- [x] 최종 우승자를 출력한다.

- [ ] 자동차 이름이 비어있는 경우 예외를 발생시킨다.
- [ ] 자동차 이름이 중복되는 경우 예외를 발생시킨다.
