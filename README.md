# 자동차 경주

자동차 이름과 시도 횟수를 입력받아 경주를 진행하는 콘솔 프로그램입니다.
경주가 끝나면 가장 멀리 이동한 자동차를 우승자로 출력합니다.

## 1, 2단계

### 자동차

- 자동차는 이름과 현재 위치를 가집니다.
- 자동차의 시작 위치는 0입니다.
- 이동 여부를 판단할 때 사용하는 숫자의 범위는 0~9입니다.
- 숫자가 4 이상이면 한 칸 전진합니다.
- 숫자가 3 이하이면 현재 위치를 유지합니다.

### 경주 진행

- 지정한 횟수만큼 경주를 반복합니다.
- 매 회차 자동차마다 숫자를 생성하고 이동 여부를 판단합니다.

### 우승자 판별

- 경주가 끝나면 자동차들의 위치를 비교합니다.
- 가장 멀리 이동한 자동차를 우승자로 선정합니다.
- 가장 멀리 이동한 자동차가 여러 대라면 공동 우승으로 처리합니다.

### 결과 출력

- 우승한 자동차의 이름을 쉼표로 구분하여 출력합니다.
- 출력 예시: `neo, brown가 최종 우승했습니다.`

## 3, 4단계

### 게임 실행

- main 메서드를 추가하여 프로그램을 실행할 수 있도록 합니다.
- 자동차 이름을 쉼표로 구분하여 입력받습니다.
- 자동차 이름은 1~5자로 제한하며, 공백으로만 된 이름은 허용하지 않습니다.
- 경주 시도 횟수를 입력받습니다.
- 시도 횟수가 음수이거나 정수가 아니면 안내 문구를 출력하고 다시 입력받습니다.
- 매 회차 모든 자동차의 이름과 현재 위치를 출력합니다.
- 랜덤 숫자는 Random 클래스의 nextInt(10)을 사용하여 생성합니다.

## MVC 패턴으로 구조 나누기

기존에는 Application에서 입력, 경주 진행, 출력을 모두 처리했습니다.
역할을 구분하기 위해 게임 로직은 domain에, 입력과 출력은 view에 나누어 작성합니다.

### domain

- Car: 자동차 이름과 위치를 관리하고, 이름 검증과 이동 판단을 담당합니다.
- RacingGame: 경주를 진행하고 우승자를 찾습니다.
- NumberGenerator: 경주에 사용할 숫자를 생성하는 기능을 정의합니다.
- RandomNumberGenerator: 0~9 사이의 난수를 생성합니다.

### view

- InputView: 자동차 이름과 시도 횟수를 입력받고 처리합니다.
- ResultView: 매 회차 자동차 위치와 최종 우승자를 출력합니다.

Application은 입력받은 값으로 경주를 진행하고,
결과를 출력하도록 연결하는 역할을 합니다.

view에서는 domain을 사용할 수 있지만, domain에서는 view를 사용하지 않도록 합니다.

## 테스트

키보드 입력과 콘솔 출력은 단위 테스트에서 제외합니다.
입력받은 문자열을 처리하는 부분은 별도 메서드로 나누어 테스트합니다.

### 테스트할 내용

- 자동차의 시작 위치가 0인지 확인합니다.
- 올바르지 않은 자동차 이름에 예외가 발생하는지 확인합니다.
- 숫자가 4 이상이면 이동하고, 3 이하이면 멈추는지 확인합니다.
- 쉼표로 구분한 이름이 자동차 목록으로 변환되는지 확인합니다.
- 시도 횟수가 정수로 변환되고, 음수는 거부되는지 확인합니다.
- 지정한 횟수만큼 경주가 진행되는지 확인합니다.
- 단독 우승자와 공동 우승자를 올바르게 찾는지 확인합니다.

경주 테스트에서는 랜덤 숫자 대신 FixedNumberGenerator로 고정된 숫자를 전달합니다.
이를 통해 실행할 때마다 결과가 달라지지 않고,
예상한 만큼 자동차가 이동하는지 확인할 수 있습니다.
